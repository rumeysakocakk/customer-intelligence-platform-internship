# Customer Intelligence Platform Internship

An end-to-end machine learning internship project focused on customer intelligence using the Olist Brazilian E-commerce dataset.

---

## Project Objective

The primary objective of this project is to develop an end-to-end machine learning pipeline capable of extracting meaningful insights from e-commerce data and supporting customer intelligence applications.

The project aims to:

- Understand and explore customer behavior through data analysis.
- Clean and preprocess raw data for machine learning.
- Perform exploratory data analysis to identify patterns and business insights.
- Engineer meaningful features for predictive modeling.
- Develop and evaluate machine learning models.
- Build a simple deployment solution to demonstrate the final model.

---

## Project Workflow
